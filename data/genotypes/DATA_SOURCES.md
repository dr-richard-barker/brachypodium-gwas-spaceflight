# Data sources

Where each data file in this repository comes from. Checked 2026-10-14.

## 1. NASA OSDR OSD-375 (APEX-06)

- **Study:** <https://osdr.nasa.gov/bio/repo/data/studies/OSD-375>, DOI [10.26030/2x6b-3v89](https://doi.org/10.26030/2x6b-3v89).
- **Files:** `code/01_download_osdr_osd375.py` downloads the file listing and ISA-Tab metadata from
  `https://osdr.nasa.gov/osdr/data/osd/files/375`. OSDR holds raw FASTQ files, MultiQC reports and md5 sums for this study;
  it has no count matrices or differential-expression tables.
- **Paper:** Su S-H, Levine HG, Masson PH (2023). Brachypodium distachyon Seedlings Display Accession-Specific Morphological
  and Transcriptomic Responses to the Microgravity Environment of the International Space Station. *Life* 13(3):626.
  DOI [10.3390/life13030626](https://doi.org/10.3390/life13030626).

## 2. Gravitropism candidate genes (this folder)

- `candidate_genes_curated.csv`: the hand-curated list. Each candidate is named after the Arabidopsis gene it follows,
  with the Arabidopsis identifier (AGI) given for it and the Brachypodium identifier the list gave before 2026-10-14
  (`withdrawn_bradi_id`).
- `arabidopsis_anchor_check.csv`: UniProt gene names for each AGI, from `code/14_check_arabidopsis_anchors.py`
  (UniProt REST API, reviewed entries, Araport cross-reference; release recorded in the file).
- `withdrawn_bradi_id_check.csv`: for each withdrawn BRADI identifier, whether it exists in Ensembl and, for verified
  anchors, whether it is among the anchor's Brachypodium orthologs in Ensembl Compara (plants). Also from
  `code/14_check_arabidopsis_anchors.py`; the Ensembl Genomes release is recorded in the file.
- `gravitropism_candidate_genes.csv`: the combined table, built by `code/03_candidate_genes.py`.

## 3. Gravitropism plots (`data/phenotypes/`)

PNG plots of root orientation and root-tip displacement per accession, and summary histograms, added in commit
`b9dac85` as "Barker_2016 data". **TODO:** record the source of these plots and add the measurements behind them; the
numbers are not in this repository.

There are no gravitropism measurements in the repository. The `data/gwas_phenotypes/gravitropism_data.csv` committed
before 2026-10-14 was generated by the pipeline's former `--demo` mode (seeded random numbers) and was removed.

## 4. Genotype data

No genotype data are in this repository, and no association study has been run. A future candidate-gene comparison
would need genotypes for the phenotyped accessions, for example from the *B. distachyon* pan-genome lines
(Gordon et al. 2017, *Nature Communications* 8:2184, DOI [10.1038/s41467-017-02292-8](https://doi.org/10.1038/s41467-017-02292-8)),
distributed through JGI Phytozome (login required).
